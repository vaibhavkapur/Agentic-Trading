# Macro Intelligence Agent

Revision-aware macroeconomic release and central bank communication intelligence prototype with strict UTC publication gates, verifiable character-span citations, unit/conflict abstention guardrails, untrusted-text sanitization, and deterministic SQLite replay.

> **Scope & Limitations Notice:** Macro interpretations generated by this agent are structured **hypotheses**, not predictions, forecasts, or trading recommendations. No consensus values or market impacts are fabricated. Live capital, real customer records, live network feeds, and production credentials are excluded.

## Key Capabilities

- **Publication-Gated Vintage Archive (`archive.py`):** SQLite archive enforcing `available_at = max(published_at, embargo_until) <= as_of_utc` in both SQL and Python so future or embargoed releases are never visible at historical cutoffs.
- **Verifiable Extraction & Policy Cues (`extractor.py`, `verification.py`):** Extracts figures and central bank policy language cues (`hawkish`, `dovish`, `neutral`, `data_dependent`) with deterministic SHA-256 `Citation` records pinned to exact `[char_start:char_end]` spans and document hashes.
- **Revision Diffs, Unit Guards & Conflict Abstention (`revisions.py`):** Tracks multi-vintage revisions (`v1 -> v2`), performs lossless conversions only for compatible units (`bps <-> %`, `millions <-> thousands`), and explicitly abstains on periodicity mismatches (`% MoM` vs `% YoY`), competing/conflicting reports, or missing consensus.
- **Untrusted-Text Guardrails (`security.py`):** Treats all retrieved text as untrusted data; detects prompt-injection / instruction-override directives and quarantines (offset-preserving mask) or rejects them (`UntrustedInstructionError`).
- **Budgeted Brief Synthesis & Replay (`briefs.py`, `service.py`):** Separates the optional/pluggable `SummarizerAdapter` (defaulting to an offline, fixed-budget `DeterministicMockSummarizer`) from deterministic verification and persists runs for exact replay.

## Quickstart

Requires **Python 3.9+** (zero external runtime dependencies).

```bash
cd macro-intelligence-agent

# 1. Run full unit, integration, security, and operational test suite
PYTHONPATH=src python3 -m unittest discover -s tests -p "test_*.py" -v

# 2. Run reproducible end-to-end demo (writes raw outputs to reports/)
python3 scripts/run_demo.py

# 3. Run curated gold-set acceptance evaluation
python3 scripts/run_acceptance.py

# 4. Run full local CI validation
bash scripts/ci_check.sh
```

### CLI Usage

```bash
PYTHONPATH=src python3 -m macro_intelligence_agent brief \
  --fixture data/fixtures/reference_cpi_release.json \
  --series-group US_INFLATION_POLICY \
  --as-of 2025-05-13T13:00:00Z \
  --config config/default_config.json
```

## Assumptions and Known Limitations

- **Synthetic fixtures only:** Evaluation measures correctness on curated synthetic fixtures; live statistical agency PDFs/HTML tables and wire feeds are not ingested.
- **Deterministic extraction scope:** Unstructured raw-text regex fallback covers core canonical series (`US_CPI_HEADLINE`, `US_CPI_CORE`, `US_NFP`, `FED_FUNDS_TARGET_UPPER`) and a curated policy lexicon; broader series rely on grounded `reported_metrics`.
- **Untested optional integrations:** Live LLM API calls are disabled (`allow_live_network=false`); optional `pydantic`, `pytest`, `ruff`, and `mypy` extras were not executed in the offline environment.
